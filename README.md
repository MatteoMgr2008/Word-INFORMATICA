## 🇮🇹 Italiano

### 📄 Descrizione
Raccolta di esercizi svolti in classe con **Microsoft Word** per la materia **Informatica**. Gli esercizi riguardano la scrittura e la formattazione di documenti di testo.

### 📁 Contenuto
| File | Descrizione |
|------|-------------|
| `Esercizi in classe/ecdl.docx` | Documento sul protocollo d'intesa del 1999 tra il Ministero della Pubblica Istruzione e l'AICA riguardante l'ECDL. |
| `Esercizi in classe/saggio.docx` | Locandina/invito a un saggio di ginnastica artistica, con immagini inserite nel documento. |

### 🛠️ Strumenti utilizzati
- **Microsoft Word** (formato `.docx`)

### ▶️ Come aprire i file
Apri i file `.docx` con **Microsoft Word** oppure con un programma compatibile (ad esempio LibreOffice Writer o Google Documenti).

## 🇬🇧 English

### 📄 Description
A collection of exercises done in class with **Microsoft Word** for the **Computer Science** (Informatica) subject. The exercises focus on writing and formatting text documents.

### 📁 Contents
| File | Description |
|------|-------------|
| `Esercizi in classe/ecdl.docx` | Document about the 1999 memorandum of understanding between the Italian Ministry of Public Education and AICA concerning the ECDL. |
| `Esercizi in classe/saggio.docx` | Flyer/invitation for an artistic gymnastics show, with images embedded in the document. |

### 🛠️ Tools used
- **Microsoft Word** (`.docx` format)

### ▶️ How to open the files
Open the `.docx` files with **Microsoft Word** or a compatible program (e.g. LibreOffice Writer or Google Docs).
